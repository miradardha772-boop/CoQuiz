​🎯 CoQuiz Game
​A dynamic, interactive command-line quiz application built using Python. This project tests general knowledge across multiple categories while demonstrating core programming fundamentals and structured control flow.
​✨ Features
​Interactive Gameplay: Prompts users with multiple-choice questions directly in the console.
​Automatic Input Sanitization: Handles extra spaces and case sensitivity seamlessly (e.g., handles A, a, b, etc.).
​Dynamic Score Tracking: Automatically calculates final points and score percentages based on the total number of questions.
​Instant Feedback: Provides immediate confirmation on answers or displays the correct choice if missed.
​🛠️ Concepts & Skills Demonstrated
​Data Structures: Python lists and dictionaries used to store and manage quiz questions.
​Control Flow: if/else statements for answer validation and conditional feedback.
​Loops: for loop with enumerate() for clean, repeatable question iteration.
​Input/Output: input() for real-time user interaction and print() for formatted terminal outputs.
​🚀 How to Run
​Ensure you have Python 3.x installed.
​Clone or download this repository.
​Run the script using:python coquiz.py
